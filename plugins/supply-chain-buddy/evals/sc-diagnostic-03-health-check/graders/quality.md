PASS only if ALL of the following hold:
1. Proposes a structured assessment across supply chain process areas (e.g. SCOR-style Plan / Source / Make or Transform / Deliver or Fulfill / Return / Enable or Orchestrate, or an equivalent complete structure).
2. Asks the user a manageable first set of concrete questions and/or requests specific KPIs with definitions (e.g. forecast accuracy and bias, fill rate/OTIF, inventory days/turns, supplier on-time delivery).
3. Explains how the results will be turned into a maturity view and prioritised (e.g. maturity scale, heatmap, impact × feasibility, link to business strategy).

FAIL if the response invents maturity scores or findings for the user's company without having received any information.
FAIL if it asks more than ~12 questions in a single turn without structure.
