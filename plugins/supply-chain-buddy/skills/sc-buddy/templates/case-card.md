# Case card

*Keep it short. Update it after each major step. Show it at the start of a multi-step case and whenever it changes materially.*

| | |
|---|---|
| **Decision** | *e.g. "Which actions restore fill rate to ≥ 95% within one quarter without raising inventory?"* |
| **Owner / deadline** | *role, date* |
| **Symptom (facts)** | *KPI, from → to, since when, scope* |
| **Data received** | *files or figures; tier T0–T3* |
| **Assumptions** | *[Assumption] …* |
| **Route** | *e.g. sc-diagnostic ✅ → demand-planning-review ⏳ → inventory-policy ⏳* |
| **Findings so far** | *1–3 bullets with numbers and confidence* |
| **Open questions** | *max 3* |
